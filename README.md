# computer control

DeepSeek Harness 插件：一个看得见、点得准、能验证的电脑控制器，外加一个会看你操作并整理成技能的学习器。两种状态可以随时切换。

## 两个大功能

### 1. 控制电脑（control）

- 常驻 C# helper（首次运行时用系统自带 `csc.exe` 现场编译，之后复用），Per-Monitor-V2 DPI aware，坐标统一是物理像素。
- 鼠标：移动、左/右/中键、双击、拖拽、滚轮；键盘：组合键、Unicode 打字（中文、标点都能输入）。
- **每次动作都是闭环**：动作前截图 → 执行 → 轮询 1.6 秒看变化 → 返回「生效 / 没变化 / 未判定」+ 变化比例 + 变化区域 + 动作后的截图。
- 截图会画十字准星标出点击点、显示坐标，并在右下角附 2 倍放大镜，所以「点在哪里、屏幕长什么样」一眼能核对。
- `cc_look` 同时给出 UI Automation 元素清单（ref 编号、类型、名称、中心坐标），可以按 ref 精确点击，而不是靠估坐标；ref 绑定的快照 20 秒内有效，过期会要求重新看。
- 小目标/小字用 `cc_look` 的 `region` + `zoom` 局部放大（2–4 倍）；`cc_act` 每次也会返回点击点的 3 倍放大图。
- `cc_act` 结果会说明「该点下面是什么」：窗口标题、进程、UIA 元素类型和名称；查不到元素的游戏/自绘界面会明确说明，只退化成窗口+进程，不会报错。
- 点空了不会硬连点：默认只做一次，把「没变化」和截图交回来，由模型决定下一步。

### 2. 观看学习（watch）

- 按 2 帧/秒采样屏幕，只在画面变化超过阈值时留图（省磁盘，也能直接当时间线用）。
- 空闲自动降频：连续 2 秒没有变化就降到 0.5 帧/秒，一有变化立刻回到 2 帧/秒；依然只在变化时落盘，静止时通常只有一张基线图。
- 全局低级钩子记录真实的鼠标点击、滚轮、键盘按键，并带上当时的窗口标题和进程。
- `cc_learn start` 开始录制一段操作：画面变化帧 + 输入事件 + 窗口切换一起记，`stop` 后生成 `timeline.md`（按时间排序的完整操作流水）和 `events.jsonl`。
- 学会之后可以用 `cc_learn save_skill` 把流程沉淀成技能 markdown，下次 `read_skill` 读出来照着做。

## 悬浮岛（置顶小组件）

屏幕上方会浮一个「灵动岛」式的小条，控制电脑或观看学习时出现，回到待机 2 秒后自动收起。

- 两行信息：第一行是当前状态和最近一次操作（比如 `点击 (1200, 340)`、`拖动 (1200, 31) → (800, 200)`、`打字 12 字`、`按键 ctrl+s`、`滚轮 3 格`），第二行实时显示当前聚焦窗口的标题和进程，每秒刷新；放不下时按当前宽度自动省略
- 累计步数不在悬浮岛上显示，用 `cc_log` 看
- 右边三个按钮：**停止**（始终可用，立刻结束当前行为回到待机）、**锁图标**（开锁/关锁）、**×**（关掉悬浮岛）
- 锁定后：× 隐藏，不能拖动也不能关闭；开锁后才拖得动、才能点 × 关闭
- 点 **×** 之后，后续控制/观看都不再弹出，直到在设置页点「重置浮窗位置」
- 按住小条可拖动；真正拖动后位置自动记为「自定义」并持久化，单纯点锁不会改位置
- 位置、锁定状态、长度、透明度都存在 `%USERPROFILE%\.dsh\computer-control\config.json`，插件重启、DSH 重启后都按上次的来；「重置浮窗位置」只重置位置，不动锁定/长度/透明度
- 开锁时拖左右边缘可以调长度，两边对称一起伸缩（中心不动），宽度会记住；设置页也能直接填 300–900
- 透明度可调，默认 85%（30%–100%），设置页调完立即生效并记住
- 设置页可以选顶部居中 / 左上 / 右上 / 自定义，也能开关、锁定、重置位置
- 平时对截屏不可见（不干扰动作验证），设置页的「预览 5 秒」会临时允许截到，方便看样式
- 打开/收起有动画：收起时两侧向中间收成一个圆，再缩小淡出；打开反过来从圆展开
- 控制动作的目标点如果正好压在悬浮岛上，悬浮岛会临时隐藏，动作结束后自动回来；AI 注入的点击也按不到悬浮岛上的按钮，只有真人点才生效
- 独立置顶窗口、不抢焦点，点它不会打断你正在打的字

## 状态

| 状态 | 能做什么 |
|---|---|
| `control` | 看屏幕、点鼠标、打字；每次动作带判定和截图 |
| `watch` | 只看不动：采集画面变化、记录输入、学习流程 |
| `idle` | 待机，不采集也不动作 |

切换用 `cc_mode {action:"set", mode:"control|watch|idle"}`；当前状态会写进系统提示和每次工具返回里，所以模型清楚自己在哪一步。切到 control 会停掉采集；学习录制中不允许切走，先 `cc_learn stop`。

## 设置页

DSH 设置侧边栏里有一张 **computer control** 卡片（和「B站伙伴」同一类）：

- 看当前状态、累计动作数、helper 是否在跑、前台窗口和屏幕尺寸
- 一键切 `待机 / 控制电脑 / 观看学习`
- 开始/停止观看采集，开始/停止学习录制（带任务名）
- 悬浮岛开关、位置（居中/左上/右上/自定义）、长度、透明度、锁定位置、预览 5 秒、重置浮窗位置
- 查看存储占用，清理截图、变化帧、过期学习记录（技能不删）
- 修改学习记录保留天数、自动清理延迟；一键打开数据目录

卡片走本机同源接口 `/api/computer-control`，不经过模型，点了立即生效。

## 工具

| 工具 | 作用 |
|---|---|
| `cc_mode` | 查看 / 切换状态 |
| `cc_look` | 截图（可选网格/局部放大）+ 前台窗口 + 可点元素清单（ref、中心坐标） |
| `cc_act` | 点击/双击/右键/移动/拖拽/滚轮/按键/打字/等待；带 `preview` 预览、`expect` 判定条件，返回该点元素信息和 3 倍放大图 |
| `cc_verify` | 不动手，只验证画面变化 / 窗口出现 / 文字出现 / 画面安静 |
| `cc_watch` | 开始、查看、停止观看采集；peek 返回最近变化帧和你的操作 |
| `cc_learn` | 录制、停止、列出、读取、保存/读取技能 |
| `cc_log` | 回看最近每一步做了什么、坐标和判定 |
| `cc_storage` | 查看 / 清理存下来的截图、变化帧、学习记录（技能不删） |

## 判定机制

- 全屏：64×36 网格 HSV/RGB 差分，阈值 0.25%。
- 目标周边：点击点周围 460×340 的局部差分，阈值 0.4%，小控件的变化也能抓住。
- 窗口：前台窗口标题变化也算生效（例如打开对话框、文档变成「未保存」）。
- 文字：`cc_verify {kind:"text"}` 通过 UI Automation 读窗口文字确认。

## 数据目录

`%USERPROFILE%\.dsh\computer-control\`

| 位置 | 内容 | 保留策略 |
|---|---|---|
| `tmp/` | 动作前后的截图 | 超过 2 小时自动删 |
| `watch/` | 观看时的变化帧 | 每次开始观看时清空，最多 400 张滚动 |
| `sessions/` | 学习记录（时间线、事件、帧图） | 默认保留 30 天，`config.retentionDays` 可改，0 = 不自动删 |
| `skills/` | 沉淀下来的技能 markdown | 长期保留，不自动删 |
| `state.json` / `steps.jsonl` | 当前状态、动作流水 | 长期保留，很小 |
| `config.json` | 保留天数、清理延迟、悬浮岛开关/位置/锁定 | 长期保留，可手改 |

用 `cc_storage {action:"status"}` 看各块占用；`cc_storage {action:"clean", area:"tmp|watch|sessions|all", days:30}` 手动清理（技能永远不会被它删掉）。

自动清理不是固定周期：每次工具响应结束后排一个 30 分钟后的一次性任务；重复排期只保留最晚的那次（连续调用不会叠加，只会把时间往后推）。到点时如果正在观看或录制，就顺延 30 分钟再试。手动清理变化帧也要求先停掉观看。

`helper/CCHelper.exe` 是编译产物，删掉后下次使用会自动重新编译。

## 安装 / 卸载

```bash
git clone https://github.com/M0Yun/dsh-computer-control.git
```

然后在 DSH 桌面端 profile 里把它作为本地 bundle 安装（profile 的 `dependencies` 写 `link:<本插件目录>`，`dsh.profile.bundles` 里加 `dsh-computer-control`），再在 profile 目录执行：

```powershell
pnpm install
```

也可以直接用插件管理器安装这个目录。卸载就是从这两处去掉、重新安装依赖；数据目录可以自己删。

## 已知限制

- 目标程序以管理员权限运行时，`SendInput` 会被系统丢掉，会明确报错；需要同权限启动 DSH。
- 锁屏 / UAC 安全桌面下无法注入，也无法可靠截图。
- 浏览器等少数窗口的 UI Automation 树很浅（只暴露 `Chrome Legacy Window`），这时用截图 + 坐标；浏览器操作优先用浏览器工具。
- 观看采集默认 2 帧/秒（空闲降到 0.5 帧/秒），快速动画可能只留下一帧代表画面。

## 安全约定

- 只在 `control` 状态下才允许动作；`watch` 状态调用 `cc_act` 会被拒绝并提示切换。
- 打字/按键/拖拽前检查你的空闲时间，检测到你正在操作就停手。
- 不输入密码；发送、删除、购买这类不可逆操作，模型应先 `preview` 再执行。
- 每个动作都留截图和步骤记录，事后可以用 `cc_log` 复盘。
